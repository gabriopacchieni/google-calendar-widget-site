# Privacy Policy

**Google Calendar Desktop Widget**

Last updated: October 14, 2026

## 1. Overview

Google Calendar Desktop Widget is a personal desktop application for Windows 11 developed using Python and PySide6.

The application displays Google Calendar events on the user's desktop.

## 2. Information accessed

With the user's explicit permission, the application accesses Google Calendar data through the Google Calendar API.

This may include:

- Calendar names and identifiers
- Event titles and descriptions
- Event dates and times
- Event locations and other event metadata

The application requests read-only access and does not modify or delete calendar events.

## 3. How information is used

Calendar information is used exclusively to display calendar events and upcoming appointments in the desktop widget.

The application periodically retrieves updated calendar information to keep the displayed events synchronized.

## 4. Data storage and security

OAuth authentication tokens are stored locally on the user's computer to maintain authorized access.

Calendar information is processed locally for display within the application.

The application does not operate an independent server for collecting Google Calendar data.

## 5. Data sharing

The application does not sell Google user data or share calendar information with advertisers or third-party analytics providers.

Data is exchanged with Google services only as necessary to authenticate the user and retrieve calendar events.

## 6. Data retention and deletion

Users may revoke the application's access through their Google Account security settings.

Locally stored authentication tokens can be deleted from the application's configuration directory.

Removing the application and its locally stored configuration files removes the application's locally retained authentication information.

## 7. Google API Services

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## 8. Changes to this policy

This Privacy Policy may be updated if the application's functionality or data-handling practices change.

## 9. Contact

Privacy-related inquiries may be directed to the developer through the support email displayed on the Google OAuth consent screen.
