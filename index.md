# Google Calendar Desktop Widget

A personal desktop calendar application for Windows 11, built with Python and PySide6.

## About the application

Google Calendar Desktop Widget displays Google Calendar events in a convenient desktop interface.

### Features

- Monthly calendar view
- Upcoming calendar events
- Automatic synchronization every five minutes
- Semi-transparent desktop interface
- Optional automatic startup with Windows

## Google Calendar integration

The application uses the official Google Calendar API and OAuth 2.0 authentication to access calendar information with the user's permission.

The application is designed for personal use and requests read-only access to Google Calendar.
